# Dizziness Triage — public website

This repository contains only the static files published at:

https://akassab-umich.github.io/dizziness/

The development source, research scripts, workbooks, patient case files, and
analysis outputs are maintained separately. Patient-level data must never be
committed to this repository.

Website releases are copied from the private source repository's `dist/`
directory and deployed automatically by GitHub Pages.
